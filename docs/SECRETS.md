SECRETS TO ADD (Settings → Secrets)

- FIREBASE_CONFIG (project JSON or base64)
- ANDROID_KEYSTORE (base64) / ANDROID_KEYSTORE_PASSWORD / ANDROID_KEY_ALIAS / ANDROID_KEY_PASSWORD
- APPLE_API_KEY / FASTLANE_SESSION (for iOS publish)
- GOOGLE_PLAY_SERVICE_ACCOUNT_JSON
- DATABASE_URL (Postgres)
- REDIS_URL
- STRIPE_SECRET_KEY / FLUTTERWAVE_SECRET / PAYDUNYA_KEY (placeholders)
- SENTRY_DSN (optional)

Add these before enabling CI workflows.
